**README**

Matchup Control grades every one-on-one pass-protection rep — one blocker against the rusher PFF assigned him — from NFL player tracking, measuring the geometry of the block (ground given up toward the QB, whether the blocker stayed attached and shielded the passer) and turning it into a single control grade using logistic regression validated against PFF's hit/hurry/sack labels. A Streamlit dashboard shows the results across tabs: a per-lineman leaderboard filterable by team and position, a "how it works" page with the validation and feature importance, a film-room view that draws any single block as field paths plus a control-over-time curve, a team view, and a bonus receiver-vs-defender head. To run it, pip install -r requirements.txt, make sure the nfl-big-data-bowl-regional-event-data/data/ folder is in place next to matchup/, then launch from the repo root with streamlit run matchup/app.py. Click Run pipeline in the sidebar to compute the grades (results are cached, so it's instant on later runs).
